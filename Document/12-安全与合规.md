# 12 - 安全与合规

> 系统要安全上线，必须把角色权限、数据可见范围、敏感数据处理、模型调用边界和审计记录定清楚。这份文档不是泛泛的安全口号，是落到具体规则的。

## 2. 数据可见范围

| 数据类型 | 可见范围 | 说明 |
| --- | --- | --- |
| 用户个人信息 | 仅本人和管理员 | 用户名、邮箱、手机号、公司信息 |
| 对话记录 | 仅对话发起者 + 客服主管 | 终端客户只看自己的对话 |
| 工单信息 | 创建者 + 分配网点 + 客服主管 | 不同角色看到不同范围的工单 |
| 知识库内容 | 所有已登录用户（通过 AI 回答间接访问） | 知识库内容不直接暴露原始文档 |
| 设备信息 | 所有已登录用户 | 产品规格公开，保修信息需序列号查询 |
| 系统日志 | 仅客服主管 | AI 调用日志、操作审计日志 |

## 3. 敏感数据处理

### 3.1 不允许进入 Prompt 的数据

| 数据类型 | 处理方式 |
| --- | --- |
| 用户密码 | 仅存储 bcrypt 哈希，不传输给大模型 |
| JWT Token | 仅在 API 层校验，不传入 AI 链路 |
| 设备序列号 | 可作为 Agent 工具调用参数查询，但不直接拼入 Prompt 上下文 |
| 用户手机号/邮箱 | 仅在工单字段中传递，不进入大模型推理 |

### 3.2 脱敏规则

*   对话记录中出现的手机号在管理后台展示时部分遮蔽（如 138\*\*\*\*5005）
    
*   工单导出时联系方式字段自动脱敏
    
*   日志中的 API Key 不记录完整值
    

## 4. 模型调用边界

| 规则 | 说明 |
| --- | --- |
| 用户输入不直接作为 Prompt | 用户问题经过意图分类和关键词提取后，与检索文档一起构建 Prompt |
| AI 回答中的实体信息必须可溯源 | 型号、版本号、参数值等关键实体必须在知识库或设备信息表中可查到 |
| 固件版本号不允许 AI 生成 | 如果知识库中无该型号固件信息，AI 回答中不出现版本号，改为引导用户查看官网 |
| 安全相关操作必须附加警告 | 涉及强电、高空作业、防爆设备的操作建议，一律附加安全提示 |

## 5. 审计记录

| 审计事件 | 记录内容 | 保留时间 |
| --- | --- | --- |
| 用户登录/登出 | 用户 ID、IP、时间、登录结果 | 90 天 |
| AI 对话调用 | 对话 ID、用户 ID、意图类型、置信度、是否转人工 | 180 天 |
| Agent 工具调用 | 工具名称、输入参数、返回结果、耗时 | 90 天 |
| 知识库变更 | 操作人、文档 ID、操作类型（上传/更新/删除/状态变更） | 365 天 |
| 工单状态变更 | 操作人、工单 ID、旧状态、新状态、备注 | 365 天 |
| 权限变更 | 操作人、目标用户、变更内容 | 365 天 |

## 6. 合规注意事项

| 类别 | 要求 |
| --- | --- |
| 数据本地化 | 对话数据和用户数据存储在国内服务器，百炼平台为阿里云国内服务 |
| 隐私政策 | 用户注册时需同意隐私政策，明确告知 AI 对话数据会被存储和分析 |
| API 频率限制 | 单用户每分钟最多 30 次 AI 对话请求，防止滥用 |
| 数据删除权 | 用户可申请删除自己的对话记录和工单数据 |
