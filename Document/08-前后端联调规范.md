# 08 - 前后端联调规范

> 这份文档定义前后端之间的接口契约——每个 API 的路径、请求参数、响应格式、错误码都写在这里。前后端按这份文档并行开发，联调时以这份文档为准。

## 1. 通用规范

### 1.1 基础约定

| 项目 | 规范 |
| --- | --- |
| 基础路径 | `/api/v1` |
| 数据格式 | JSON（`Content-Type: application/json`） |
| 鉴权方式 | Bearer Token（JWT），放在 `Authorization: Bearer <token>` 请求头 |
| 时间格式 | ISO 8601（`2026-06-09T12:00:00Z`） |
| 分页参数 | `page`（页码，从 1 开始）、`page_size`（每页条数，默认 20） |

### 1.2 统一响应结构

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

### 1.3 统一错误响应

```json
{
  "code": 40001,
  "message": "用户名或密码错误",
  "data": null
}
```

### 1.4 错误码定义

| 错误码 | 含义 | HTTP 状态码 |
| --- | --- | --- |
| 200 | 成功 | 200 |
| 40001 | 用户名或密码错误 | 401 |
| 40002 | Token 过期 | 401 |
| 40003 | 无权限 | 403 |
| 40004 | 资源不存在 | 404 |
| 40005 | 参数校验失败 | 422 |
| 42901 | 请求频率超限 | 429 |
| 50001 | 服务器内部错误 | 500 |
| 50002 | AI 模型调用超时 | 504 |
| 50003 | AI 模型调用失败 | 502 |

## 3. P0 接口详细定义

### 3.1 POST /auth/login

**请求**：

```json
{
  "username": "zhang_wei",
  "password": "password123"
}
```

**响应**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIs...",
    "token_type": "bearer",
    "expires_in": 3600,
    "user": {
      "id": 1,
      "username": "zhang_wei",
      "user_type": "integrator",
      "company_name": "杭州安盾系统集成有限公司"
    }
  }
}
```

### 3.2 POST /chat/stream（SSE 流式）

**请求**：

```json
{
  "question": "DS-2CD3T86 画面模糊怎么办？",
  "conversation_id": 1
}
```

*   `conversation_id` 可选，不传则自动创建新对话
    
*   响应为 SSE 流（`Content-Type: text/event-stream`）
    

**SSE 事件格式**：

```plaintext
data: {"type": "token", "content": "您好"}
data: {"type": "token", "content": "，画面模糊"}
data: {"type": "token", "content": "请按以下步骤"}
data: {"type": "metadata", "confidence": 0.88, "sources": [{"doc_id": 1, "title": "DS-2CD3T86FWDV2 产品手册"}]}
data: {"type": "done", "message_id": 42, "conversation_id": 1}
```

### 3.3 POST /messages/{id}/feedback

**请求**：

```json
{
  "rating": "useful",
  "comment": "按照步骤解决了问题"
}
```

*   `rating`：`useful` | `not_useful`
    

### 3.4 POST /work-orders

**请求**：

```json
{
  "conversation_id": 2,
  "order_type": "fault_repair",
  "device_model": "DS-7608NI-K2/8P",
  "serial_number": "DS7608NI20230815001",
  "fault_description": "NVR 开机无画面，电源指示灯亮但HDMI无输出",
  "contact_info": "李娜 13900002002"
}
```

**响应**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "order_number": "WO-20260609-0001",
    "status": "pending",
    "created_at": "2026-06-09T14:30:00Z"
  }
}
```

### 3.5 POST /kb/documents/upload

**请求**：`multipart/form-data`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| file | File | 是 | PDF/Word/Markdown 文件 |
| title | string | 是 | 文档标题 |
| doc\_type | string | 是 | 文档类型枚举 |
| product\_model | string | 否 | 关联产品型号 |

**响应**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 6,
    "title": "DS-2CD3T86FWDV2 安装指南",
    "status": "processing",
    "message": "文档正在解析和向量化中，预计 2 分钟完成"
  }
}
```

## 4. AI 对话接口的流式响应规则

| 事件类型 | 含义 | 前端处理 |
| --- | --- | --- |
| `token` | 回答文本片段 | 追加到缓冲区，防抖渲染 Markdown |
| `metadata` | 回答完成后的元信息 | 展示置信度标签和引用来源 |
| `tool_call` | Agent 正在调用工具 | 展示"正在查询设备信息..."提示 |
| `tool_result` | 工具调用结果 | 展示结构化数据（如保修状态卡片） |
| `done` | 回答结束 | 停止流式渲染，展示反馈按钮 |
| `error` | 发生错误 | 展示错误提示 |

## 5. 联调顺序

| 阶段 | 内容 | 验收方式 |
| --- | --- | --- |
| 第一阶段 | 登录注册 + 用户信息接口 | 前端能正常登录并获取用户信息 |
| 第二阶段 | AI 对话 SSE 流式接口 | 前端能收到流式 token 并渲染回答 |
| 第三阶段 | 对话管理 + 消息反馈 | 对话列表加载、历史消息展示、反馈提交 |
| 第四阶段 | 设备查询 + 保修查询 + 工单创建 | 对话中触发工具调用、工单创建成功 |
| 第五阶段 | 知识库管理（上传/列表/状态更新） | 文档上传后异步解析、列表展示 |
